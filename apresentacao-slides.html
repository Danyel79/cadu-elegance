Objetivo do projeto

Dar ao gestor da barbearia
o máximo de controle possível
sobre o seu negócio — em um único sistema.

Da agenda dos profissionais ao caixa do mês, passando pela loja e pela equipe: uma plataforma só, sem planilhas soltas nem sistemas separados.

Como o sistema foi construído

JS

JavaScript

Linguagem base de todo o projeto: funções assíncronas e módulos usados em cada tela e serviço.

Linguagem
R

React

Monta a interface em componentes; hooks como useState e useEffect controlam o estado de cada tela.

Interface
RR

React Router

Define as rotas e protege cada área por perfil: admin, profissional e cliente só acessam o que podem.

Navegação
V

Vite

Servidor de desenvolvimento instantâneo e empacotamento otimizado para produção.

Build tool
A

Appwrite

Backend completo na nuvem: banco de dados, autenticação, permissões e armazenamento de fotos.

Backend
C3

CSS3

Estilização própria, sem framework, com a identidade visual escura e dourada da barbearia.
